## Sobre mim

Sou estudante de Engenharia da Computação na **UNIFESP**, com previsão de conclusão em **2028**. Minha experiência com automações corporativas na **Embraer** e minha visão de **Product Owner** orientam como começo um projeto. Primeiro entendo onde o processo trava, depois escolho o que automatizar e o que vale construir.

Gosto da etapa em que um modelo começa a fazer parte de um sistema. Ajusto a inferência, conecto os dados e construo a API que o produto vai usar.
